# LinkedIn Job Market Analysis

This project explores a LinkedIn job dataset to uncover insights about hiring trends, salary distribution, job roles, locations, and experience requirements. The notebook includes data cleaning, exploratory data analysis (EDA), and visualizations to better understand the job market landscape across industries.

## 📂 Project Contents
- **Data Cleaning:** Handling missing values, formatting text fields, removing duplicates.
- **Exploratory Data Analysis:**  
  - Salary trends and distributions  
  - Most demanded job titles  
  - Top hiring companies  
  - Experience requirements  
  - Geographic insights  
- **Visualizations:** Charts showing correlations, salary ranges, job role frequencies, etc.

## 🛠 Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Jupyter Notebook  
- Power BI (Dashboard included)

## 📊 Dataset Overview
Columns include:
- Job Title  
- Company Name  
- Location  
- Salary (min, max, avg)  
- Experience Required  
- Job Description  

The dataset contains **~27,000+ job listings**.

## 📈 Key Insights
- Salary ranges vary significantly by industry and location.  
- Senior roles show higher demand for experience (7+ years average).  
- Major hiring hotspots include metro cities like Sydney, Melbourne, and Brisbane.  
- Tech, management, and engineering roles dominate the dataset.

## 📦 Dashboard
A Power BI dashboard (`likedin.pbix`) is included for interactive analysis of:
- Job trends  
- Salary patterns  
- Company hiring behavior  

## 🚀 How to Use
1. Open the Jupyter Notebook to view code and analysis.  
2. Load the dataset `linkedin_data.csv`.  
3. Explore the Power BI dashboard for dynamic insights.
